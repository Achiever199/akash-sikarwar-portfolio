# Akash Sikarwar — Portfolio

Personal portfolio website built with React, TanStack Router, Tailwind CSS, and Vite.

🌐 **Live:** [akash-sikarwar-portfolio.vercel.app](https://akash-sikarwar-portfolio.vercel.app)

## Sections
- Hero, About, Education, Experience
- Skills, Projects, Achievements
- Certifications, Leadership, Contact

## Tech Stack
React · TanStack Router · Tailwind CSS · Vite · Vercel

## Projects Featured
- **WhistleVerse** — Full-stack IPL fan platform
- **Smart Air Guardian** — ML-powered air quality dashboard
- **Smart AI Quote Generator** — AI quote platform

## Run Locally
```bash
npm install --legacy-peer-deps
npm run dev
```
